# Demo 素材與生成成本規劃

更新日期：2026-08-15

## 決策順序

素材不能從角色開始。現階段順序固定為：

1. 通用卡型：先確立玩家每輪能用什麼手段破解敵方意圖。
2. 怪物：用有限、可預測的意圖牌池建立關卡題目。
3. 戰鬥 FX 與場景：驗證交鋒、連攜和 4V4 畫面是否成立。
4. 角色：最後才依卡型缺口與怪物壓力決定角色能力和美術。

角色能力、完整角色素材與 Boss 角色動畫本階段暫緩。

## 成本原則

- 固定橫向 2D，角色、敵人與其攻擊接觸點只製作朝左／朝右兩個方向；不製作八方向或自由走位素材。
- 不以拆骨架動畫作為主要方案。
- 武器與裝備不改變角色外觀或動畫，不建立換武器／換裝備的動畫分支。
- 不為每張卡、每隻怪或每個技能製作一套長逐格動畫。
- 動作主要由少量關鍵姿勢、Phaser 位移、層級、殘影、鏡頭、停格、音效及共用 FX 組成。
- AI 生成適合靜態場景、單張怪物側面圖、概念稿及紋理；不適合要求逐格一致的長動畫。
- Noise、煙霧序列、遮罩、破片、能量流與溶解優先程式生成。
- 所有生成物先列為 candidate，通過一致性、授權、provenance 與實機畫面驗證後才能轉正。

## 《Romancing SaGa》參考結論

可採用的不是它的玩法規則，而是 2D 戰鬥的素材成本分配：

- 待機輪廓保持清楚，普通攻擊只用少量起手／接觸幀。
- 技能的主要辨識來自 FX 形狀、顏色、畫面節奏、音效與命中瞬間，不要求角色本體完成長動作。
- 大招可以暫時改變場景色調、加入大型圖形或短切入，再回到共用接觸姿勢。
- 強敵才投資少量獨特動作；一般敵人不需要與玩家相同的動畫量。
- 瀕死、倒地等狀態用單一強輪廓持續顯示，避免用小字補充狀態。

不適合直接照搬的部分：

- 傳統隊列式 RPG 可讓角色原地播放技能；本作的交鋒、截刀、掩護與接力依賴空間因果，雙方仍必須實際接近與碰撞。
- 不能只用全畫面 FX 遮掉人物。交鋒勝負、誰僵直、誰接力必須由人物姿態看得出來。
- 不採用大量角色專屬武器技動畫；卡型差異由共用關鍵幀加不同 FX 配方完成。

### 建議的兩方向製程

- 所有怪物與未來角色以「朝向戰場中央」為基本構圖，同時交付 `face-left`、`face-right`。
- 第一方向先完成構圖，第二方向可由鏡像生成初稿，但武器手、服裝開襟、面具、傷痕、文字符號及不對稱飾物必須校正，不能把 runtime 水平翻轉當正式成品。
- 兩方向共用相同畫布、腳底 pivot、武器接觸點高度與輪廓占比，避免交鋒時錯位。
- 場景不需要方向版本；只需左右出入口、站位帶與鏡頭安全區都能容納任一方被擊退。

## 第一優先：通用卡型

卡片先採「少數明確動詞＋數值變體」，不以角色專屬能力填滿卡池。

| 卡型 | 玩家用途 | 必要畫面語言 | 素材成本 |
|---|---|---|---|
| 快斬 | 以速度爭取交鋒、建立破綻 | 細短刀光、快停格 | 1 組共用 FX |
| 重斬 | 利用破綻／崩勢造成高傷害 | 寬刀光、重震、地面塵 | 1 組共用 FX |
| 破甲 | 降護符／架勢，為後續連段準備 | 黃白碎片、甲片裂紋 | 1 組共用 FX |
| 堅守 | 只對自己使用，原地承受攻擊 | 原地架勢弧、受力震動 | 1 組共用 FX |
| 掩護 | 改寫一條指向隊友的殺生線 | 青白切入線、攔截火花 | 重用移動與交鋒 FX |
| 接力 | 接在已成立的攻勢後補第二刀 | 交棒殘光、無縫穿入 | 重用攻擊 FX |
| 整備 | 有成本地處理無效手牌 | 收牌／棄牌／補牌動畫 | 卡背＋紙張音效 |
| 牽制 | 延後目標或削弱下一次意圖 | 線上減速脈衝、冷色束縛 | 1 組共用 FX |

卡型規則限制：

- 不加入免費棄牌、免費追刀或免費破綻傷害。
- 整備必須消耗本輪出牌機會、棄牌本身或其他明確資源。
- 額外接力不消耗卡片的效果，未來只能放在裝備或角色被動，不能成為通用免費選項。
- 卡牌不做逐張完整插畫。Demo 使用卡型色系、招式符號、共用紋理與大數字建立辨識。
- 數字版面優先呈現威力；速度修正與消耗標記使用固定位置的小型符號，避免重複文字。

### 卡牌所需素材

- 8 種卡型圖示。
- 攻擊、防禦、支援、操作四種共用框架。
- 牌庫、棄牌、消耗三種卡背／狀態。
- 補牌、棄牌、取消的 UI 動畫曲線與音效。
- 快斬、重斬、破甲、堅守、掩護、接力、牽制七組演出配方；不是七套角色動畫。

## 第二優先：怪物設計

怪物不是隨機抽高數字，而是擁有有限意圖牌池、輪替規律與可破解弱點。

### 疾行妖

- 功能：速度壓力與改線教學。
- 牌池：低至中威力快攻、少量牽制；不連續抽最高威力。
- 弱點：架勢較低，被交鋒或連續針對容易崩勢。
- 雜魚素材：左右兩向的 `idle / action / down` 三種關鍵姿勢；受擊、頻死與崩勢由 idle/action 的角度、色調、震動及 FX 形成。
- FX：快斬、細殘影、短風壓。

### 鎮岳鬼

- 功能：高卡不能硬碰時，要求破甲、堅守與連攜。
- 牌池：慢速重擊、蓄力、少量護甲；最高威力需有公開前兆或冷卻。
- 弱點：速度慢，蓄力可被牽制；護甲破裂後架勢傷害放大。
- 雜魚素材：左右兩向的 `idle / action / down` 三種關鍵姿勢；蓄力用 idle 加光效與地面壓力圈，重擊用 action 加位移／重斬 FX。
- FX：重斬、地裂、護甲碎片、低頻震動。

### 咒返妖

- 功能：懲罰單一路線與無腦堆高卡。
- 牌池：咒術、延遲命中、條件反制；規則必須在提交前公開，不得結算時作弊改線。
- 弱點：直接受壓時架勢低，反制失敗後產生破綻。
- 雜魚素材：左右兩向的 `idle / action / down` 三種關鍵姿勢；施法、反制失敗與頻死以符紙、煙霧、失色和姿勢傾斜表現。
- FX：符紙、煙、扭曲、能量流；不做複雜肢體施法動畫。

### 怪物共用規則

- 同一遭遇每輪最多一張自然最高威力意圖；例外必須由精英／Boss 規則明示。
- 意圖必須在玩家出牌前可讀，難度來自組合與優先順序，不來自隱藏作弊。
- 小怪變體只使用配色與不影響動畫輪廓的紋理變化；不以換武器、換裝備或附件建立動畫分支。
- 敵人的攻擊、掩護被截、交鋒、崩勢與死亡全部使用共用事件節點，避免每種怪物另寫演出。

### 敵人動畫成本分級

| 等級 | 本體關鍵姿勢 | 額外成本 |
|---|---|---|
| 雜魚 | `idle / action / down`，左右兩向 | 不做專屬受擊、頻死、崩勢或招式逐格；全部由 tween、色調與共用 FX 表現 |
| 精英 | 雜魚三姿勢＋1 張專屬起手或崩勢 | 只投資能預告特殊規則的動作，不為數值變強增加動畫 |
| Boss | 基準、2～3 個規則關鍵姿勢、崩勢、倒地 | 可有部位層與階段 FX，但仍不預設骨架或長逐格動畫 |

雜魚的 `action` 是一張通用攻擊／施法接觸姿勢，不按卡片拆分。普通受擊使用短位移、染色和 hit-stop；頻死使用整體下沉、呼吸速度與低飽和；崩勢使用旋轉／後仰 tween 加架勢碎裂；死亡才切換 `down`。

## 場景素材

每個戰場採 16:9 分層背景，中央保留低對比、支援 4V4 交鋒與接力的安全區：

1. 遠景天空／月色。
2. 遠景地標。
3. 中景結構。
4. 角色站立地面。
5. 前景遮擋與氣氛層。

| 優先 | 場景 | 靜態素材 | 低成本動態 |
|---|---|---|---|
| P0 | 列車車頂 | 車頂、遠景、車廂邊緣 | 視差、風壓、速度線、煙 |
| P1 | 停靠迎擊 | 荒野／月台、遠方列車、燈火 | 霧、燈光呼吸、灰燼 |
| P1 | 離車探索 | 鳥居／林道／妖市其一 | 視差、落葉、薄霧 |
| P2 | 王前區域 | 大型地標、開闊地面 | 風壓、色調、遠景閃光 |

列車是旅行載具，不等於車廂內戰。路線圖使用程式繪線與節點，只需共用底圖、列車圖示及出發／戰鬥／事件／探索／精英／伙伴／王七種符號。

路線圖列車固定使用俯視低細節 token，而非戰鬥場景用的側視列車。現行 prototype 為 `public/assets/journey/world01/train-token-topdown.svg`：透明、無軌道、無煙、車頭朝右，可由 runtime 依路徑切線旋轉；目標顯示尺寸約 96×29 至 128×38 px。

37 是 source asset 數，不是輸出檔總數；WebP runtime、原始 PNG、atlas JSON 與縮圖不重複計入美術工作量。

### 程式化項目：不製作點陣圖

- 殺生線、當前線呼吸、截刀／掩護改線、交鋒節點與線的淡出生命週期。
- HP 墨線、護符數、五段架勢、速度數字及時序連線。
- 卡牌文字、大威力數字、速度修正、牌庫／棄牌數字與按鈕文字。
- 鏡頭推拉、命中停格、彈刀後仰、接力穿入、擊退與歸位。
- 迷霧 reveal mask、色弱線型與目前目標高亮。

### 怪物最低動畫成本

每隻雜魚只畫五張關鍵姿勢；`dying` 由 `idle` 降低重心、降低明度及加重呼吸實現，不新增圖。`hit` 優先用 `recoil-broken` 的短幅版本；`broken` 使用同一張姿勢配合架勢碎裂 FX 與較長僵直。只有 Boss 或輪廓完全無法共用時才增加姿勢。

三種怪物共 15 張 source pose：

1. 疾行妖：細長、前傾、武器或肢體形成高速斜線；規則可讀點是先手、連攻與追擊。
2. 鎮岳鬼：低重心、厚甲片或巨大軀幹；規則可讀點是堅守、甲片與高架勢。
3. 咒返妖：懸浮符紙、法器或不自然手勢；規則可讀點是改線、延後與咒返。

### 怪物生成共用提詞模板

```text
Use case: stylized-concept
Asset type: transparent side-view 2D enemy key pose for a tactical RPG
Primary request: [怪物名稱] 的 [idle / windup / strike / recoil-broken / down] 姿勢
Rule silhouette: [玩家必須從輪廓讀出的規則，例如高速連攻／厚甲堅守／符咒改線]
Style: refined painterly 2D with Japanese ink and woodblock edge texture; dark teal, charcoal, aged brass and sparse vermilion; original design
Composition: strict side view facing right; full body visible; feet share the same horizontal baseline; same canvas, scale, pivot and weapon-contact point across every pose
Animation economy: one strong readable key pose, no in-between frames, no skeletal rig, no perspective turn
Runtime support: motion, hit-stop, recoil, afterimage, particles and camera provide the remaining animation
Constraints: genuinely transparent background; no ground, shadow, UI, text, frame, watermark or baked FX; preserve the same costume, anatomy and weapon between poses
Avoid: front view, three-quarter view, eight-direction sheet, busy accessories that disappear at gameplay size, copyrighted character design
```

生成順序固定為先核准 `idle` 輪廓，再以核准圖作 reference 產其餘四姿勢；不可五張各自生成，否則角色一致性不可控。每張生成圖先進 `assets/candidates/`，經輪廓、透明邊緣、pivot、一致性與授權紀錄審查後才可進 `public/assets/`。

### P1／P2 延後項目

- 四名玩家角色：每名預估 `idle / ready / strike / recoil / broken / down` 六姿勢，共 24 張 source pose；角色規則尚未定案，因此目前不生成。
- 精英：優先沿用三種怪物其中一型，增加 1 個輪廓附件、1 個規則覆層及 1 個特殊 windup，不重做整套。
- Boss：等 Boss 規則定案後獨立估算；不得先用大量階段動畫填補未完成設計。

## 我方角色美術方向

使用者提供的黑髮紅黑女武者圖只作風格參考，來源與授權未確認，不得裁切、描圖或作為生成 edit target。採用的語言是：成熟二次元比例、墨色長髮、和風武裝、黑／朱紅／象牙配色、金屬與布料有明確材質差、輪廓帶少量妖異裝飾。

轉成戰鬥 Sprite 時必須調整：

- 由半身三分之四視角改為全身嚴格側視，臉、胸腰與武器輪廓不可互相遮蔽。
- 髮絲、束帶、金屬雕花與多層腰飾合併成 3～5 個大形；不保留縮到 160～220 px 高後不可讀的細節。
- 每名角色只選一個主輪廓標誌，例如大袖、長髮、披肩、大太刀或符帶，避免四人都以紅黑長髮女武者造成站列混淆。
- 角色魅力留在臉型、身形、髮色、服裝剪影與武器姿態，不靠每張牌專屬插畫或高成本逐格動畫。
- 四名角色共用六種姿勢規格：`idle / ready / strike / recoil / broken / down`；接力、掩護與追擊由相同姿勢配合路徑、停格及 FX 完成。

四人必須在黑色剪影下仍能辨識；建議分成「敏捷刀手／重斬武者／護衛／咒術支援」四種輪廓，但角色能力與正式武器仍待通用卡型及怪物驗收後決定。

補充畫風基準：`女主角sample.JPG` 只提供精緻二次元厚塗、乾淨臉部、柔亮髮絲、輪廓光及材質分離的參考；銀髮、螢光綠、近未來緊身服、畫面 UI 與原角色外觀全部不採用。`assets/candidates/concepts/heroine-style-costume-candidate-v1.png` 已驗證黑／朱紅和風鐵道女刀手的轉譯方向，但檔案是 24-bit RGB 且棋盤格已烘入，不具透明 alpha，只能當 identity／服裝概念，不可進 runtime。

## 共用 FX 素材庫

P0 必須完成：殺生線、快斬、重斬、金屬交鋒、相殺、受擊、破招、崩勢、斷命。

P1 補充：掩護攔截、接力交棒、取消／瓦解、破甲、牽制、咒術、腳步塵與三種場景氣氛。

共用組合方式：

| 結果 | 怪物姿勢 | 程式／FX |
|---|---|---|
| 單方面攻擊 | strike / recoil | 前衝、命中、停格、退回 |
| 相殺 | strike + recoil | 中央接觸、彈刀、雙方快速歸位 |
| 接力 | recoil 保持 | 前者退場與後者穿入同步，末刀後才復位／死亡 |
| 堅守 | idle / recoil | 守方原地震動，敵方仍完成原攻擊路徑 |
| 掩護 | strike / recoil | 敵人沿原意圖攻擊，在抵達前被守方切入攔截 |
| 崩勢 | broken | 架勢碎片、長僵直、低頻鏡頭衝擊 |
| 斷命 | down | 停止 idle、生命線斷裂、倒地或溶解 |

`dying` 是低生命常駐姿勢，不是另一套受擊動畫：降低重心、呼吸幅度變大或武器下垂即可。它只在生命跨過門檻時切換，不增加逐格長度。

## 音效需求

- 輕揮、重揮各 2～3 個變體。
- 金屬交鋒 4～6 個變體。
- 肉身／妖體命中各 2～3 個變體。
- 堅守、掩護、破甲、崩勢、斷命各 1～2 個。
- 抽牌、補牌、棄牌、選牌、取消各 1 個。
- 車頂風壓、停靠荒野、探索林道各 1 組環境聲。

避免電子提示音。UI 使用紙、木、金屬、鈴與氣流聲。戰鬥音樂維持 `demo_battle01.mp3` 的 Loop 與淡入淡出。

## 技術規格

- 怪物：透明 PNG/WebP；每個姿勢交付朝左／朝右兩向，統一畫布、腳底 pivot、武器接觸點與受擊點。
- 場景：分層 PNG/WebP，標記視差倍率與中央安全區。
- FX：PNG atlas＋JSON，或可重建的 GLSL／程式參數。
- UI 圖示優先 SVG／Phaser Graphics。
- 音訊保留 WAV source，runtime 優先 OGG。
- 所有第三方及生成素材同步更新 `assets/ASSET_PROVENANCE.md`。

## 明確暫緩

- 角色能力、角色專屬牌、完整玩家角色美術。
- 八方向、多方向死亡、完整走跑循環及骨架動畫。

- 每張卡專屬插畫或專屬長動畫。
- 每個路線節點的事件插畫。
- Boss 大量多階段素材。

## 驗收門檻

- 不依賴角色能力，通用卡型可以針對三種怪物形成不同解題方式。
- 同一怪物的意圖池不會製造無法反制的雙最高卡回合。
- 雜魚只用三種本體姿勢，仍可清楚辨識蓄力／攻擊、受擊、頻死、崩勢與斷命；若必須靠新增本體幀才能讀懂，先檢討 FX、節奏和輪廓。
- 快斬、重斬、破甲、堅守、掩護與接力即使共用姿勢，仍能靠節奏、FX、音效與鏡頭一眼區分。
- 4V4 畫面不遮住殺生線、必要狀態與中央交鋒區。
- Asset specification、provenance 與 runtime readiness 分開驗收；有規格不代表已接入遊戲。
