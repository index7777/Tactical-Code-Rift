# 戰鬥系統原創識別規範

## 機制與命名

- `ATB` 僅作程式、測試與技術討論的內部術語。
- 玩家可見名稱統一為「脈衝時序」（Pulse Timeline）。
- 商店文案、Steam 頁面、宣傳片與教學不使用 `Active Time Battle`、`ATB` 或「FF6 式戰鬥」作為賣點。
- 保留的機制：單位獨立計時、速度影響充能、滿值進入 Ready、多個 Ready 單位可切換、指令與目標提交、行動執行佇列、Active／Wait 規則。

## 原創視覺語言

- 主色：深墨黑、冷青、警示珊瑚、晶片琥珀；不使用 FF6 標誌性的皇家藍視窗。
- 面板：非對稱晶片卡、切角、細發光線及半透明層；禁止白色雙線圓角框。
- 字體：現代窄體無襯線／等寬數字；不仿 SNES 或 Pixel Remaster 像素字型。
- 充能：環形晶片脈衝、角色卡邊緣流光或分段線路；不複製 FF6 同位置水平白框計量條。
- 指令：角色專屬能力輪或切角卡片，不複製 FF6 兩欄藍窗選單。
- Ready：角色卡發光並進入 Ready Stack；只能切換 Ready 角色，未滿角色不可選擇出手。
- 敵方計時保持隱藏，以 telegraph、動作及狀態特效傳達危險。

## 橫向構圖

- 16:9 側視戰場；敵方左側，我方四人右側錯位排列。
- 戰場占高度至少 72%，HUD 不超過 28%。
- 四人常駐可見；Ready／目前輸入角色向前偏移並強化輪廓，不隱藏其他隊員。
- 手機橫向與 Steam 共用資訊架構，只調整觸控命中區與 safe area。

## 方向與移動限制

- 戰鬥是鎖定橫向軸的 2D 演出，不提供自由移動、搖桿走位、斜向追蹤或八方向控制。
- 我方固定朝左、敵方固定朝右；左右陣營互換時才允許水平翻轉。
- 攻擊移動只能沿 X 軸前進至中央交戰點或目標前方，再沿原路返回。
- 前後景錯位只使用 Y 座標、縮放與渲染層級表現，不要求角色轉向上、下或斜角。
- 受擊只允许水平击退、短暂上抛和回位；上抛不是可控制方向。
- 路径系统不得使用八方向寻路；战斗角色没有导航网格。
- 战斗 Sprite 最低方向需求为单一朝敌方向；若制作左右两阵营版本，优先使用水平翻转，不建立八方向素材契约。
- 飞空艇探索所需方向数属于独立规格，不得反向扩大战斗 Sprite 的方向需求。

## 禁止直接參考的元素

- Final Fantasy 名稱、Logo、角色、怪物、技能、音效、字型或圖像素材。
- FF6 皇家藍背景、白色雙邊框、相同視窗比例及選單排版的組合。
- 以「1:1 復刻」作為實作或宣傳目標。

## 驗收

遮住遊戲標題與角色名稱後，測試者不應只憑配色、視窗邊框及選單布局直接判斷為 FF6 仿作；同時仍能從互動理解獨立計時、Ready 切換與指令佇列。
