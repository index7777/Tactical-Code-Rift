## 完成狀態用語

只能使用以下三種狀態：

1. `規則完成，演出未完成`
2. `規則與演出已實作，尚未人工自證`
3. `規則、演出與固定情境自證全部通過`

函式存在、文字出現、測試通過、角色移到中央或建置成功，都不得單獨宣稱玩家功能完成。

## 固定自證情境

每個情境必須使用固定角色、速度、卡牌、敵方技能、目標與隨機種子：

- [ ] 正面交鋒：我方勝。
- [ ] 正面交鋒：敵方勝。
- [ ] 正面交鋒：平手。
- [ ] 高速角色改線攔截。
- [ ] 速度不足，攔截失敗並形成單方面攻擊。
- [ ] P1行動取消後，P2與P3仍繼續。
- [ ] 我方單方面攻擊有完整進場、命中與回位。
- [ ] 敵方單方面攻擊有完整進場、命中與回位。
- [ ] 角色跳過後未消耗手牌。
- [ ] 已指派卡牌立即離開可選手牌。
- [ ] 回合結束保留未使用手牌。
- [ ] 下一回合只補牌至手牌上限5。
- [ ] HUD在世界鏡頭移動時保持固定。
- [ ] 1v1、1v4、2v4、3v3、4v1與4v4沒有角色或UI重疊。
- [ ] HP 歸零者在末擊位置倒地、不回待機姿勢、不可再被點選或成為後續目標。
- [ ] 斷命當下停止角色待機動畫與循環位移；倒地後 Sprite 不得繼續換幀、浮動或播放呼吸動作。
- [ ] 死者尚未執行的本輪節拍被跳過，下一回合時序不再包含死者。
- [ ] 雙殺意雙掩護各自綁定不同敵方技能；每條保留敵人到截刀點的紅色前段，且兩次執行都有對應敵方攻擊動畫。
- [ ] 破綻與崩勢維持至本輪全部節拍結束，下一輪建立時同時清除；本輪中崩勢者不得恢復行動。
- [ ] 行動者斷命後，先前提交但尚未執行的攻擊、繼刀、掩護與支援全部取消效果；所有已提交卡仍於結算進棄牌堆，不退回手牌。
- [ ] 勝利與敗北均有正式結果層，結果層出現後停止操作與戰鬥音樂，並提供可操作的再戰入口。
- [ ] 破招顯示兵器碎光與短僵直；崩勢顯示五段刀鐔連鎖碎裂；斷命顯示命脈熄滅與倒地，縮小畫面後仍不會混淆。
- [ ] 接力首擊後目標在同一命中座標保持後仰；首位退場與第二位進場重疊，第二刀結束前不得回槽或恢復待機姿勢。
- [ ] `?journey=1` 可從出發進戰鬥，勝利後回選線；只能點相鄰節點，事件／探索／伙伴能記錄並繼續，精英後只能前往王。
- [ ] 疾行、鎮岳、咒返的速度區間與有限牌池可辨識；4 人混合敵群單輪不超過一張威力 7。
- [ ] `card-proof` 情境可看到整備、牽制、快斬、堅守、掩護五種卡面；威力徽章位於卡內且不與相鄰卡重疊。
- [ ] 整備必須占用一名角色行動，只恢復自身架勢 3 並清除破綻，不改變手牌、牌庫或棄牌堆。

## 證據要求

交鋒至少保留五個可辨識階段的截圖或短片：

1. 待機位置、敵方意圖與配對。
2. 雙方進場及技能揭示。
3. 技能／武器／FX實際對撞。
4. 敗方取消與勝方追擊。
5. 雙方回位且下一節拍繼續。

單張中央站位截圖不能證明完整交鋒。

## 測試事件記錄

測試模式應產生可核對的事件序列：

```text
CLASH_PAIR
MOVE_TO_CLASH
REVEAL_SKILL
CLASH_IMPACT
CLASH_WINNER
CANCEL_ACTION
FOLLOW_THROUGH
DAMAGE_OR_EFFECT
RETURN_STANDBY
NEXT_BEAT
```

事件記錄只能證明狀態機執行，不能取代畫面證據。

## 規則與演出分離驗收

規則測試負責交鋒配對、改線、勝負、取消範圍、節拍保留、牌庫與回合狀態。

演出驗收負責角色身份、進退場、技能卡、FX、停格、追擊、受擊、HUD固定及節拍銜接。

兩者都通過，才能使用第三級完成狀態。
