# 戰鬥功能驗收與自證規範

STATUS = AUTHORITATIVE
APPLIES_TO = 所有戰鬥規則、UI、鏡頭與演出功能

## 完成狀態用語

只能使用以下三種狀態：

1. `規則完成，演出未完成`
2. `規則與演出已實作，尚未人工自證`
3. `規則、演出與固定情境自證全部通過`

函式存在、文字出現、測試通過、角色移到中央或建置成功，都不得單獨宣稱玩家功能完成。

## 交鋒可觀察驗收表

- [ ] 明確顯示交鋒配對角色與技能槽。
- [ ] 雙方離開各自正確待機位置。
- [ ] 雙方從兩側進入中央交鋒位置。
- [ ] 雙方技能名稱與最終威力同時可讀。
- [ ] 雙方播放攻擊或交鋒準備動作。
- [ ] 武器或FX在中央實際碰撞。
- [ ] 碰撞瞬間有短暫停格與鏡頭反應。
- [ ] 敗方技能有破碎、壓制或取消演出。
- [ ] 敗方行動在規則與畫面上都被取消。
- [ ] 勝方完成正式追擊並產生傷害／效果。
- [ ] 雙方回到各自原始待機位置。
- [ ] 後續未取消的行動節拍繼續播放。

缺少任一必要項目，不得回報「交鋒演出完成」。

## 固定自證情境

每個情境必須使用固定角色、速度、卡牌、敵方技能、目標與隨機種子：

- [ ] 正面交鋒：我方勝。
- [ ] 正面交鋒：敵方勝。
- [ ] 正面交鋒：平手。
- [ ] 高速角色改線攔截。
- [ ] 速度不足，攔截失敗並形成單方面攻擊。
- [ ] P1行動取消後，P2與P3仍繼續。
- [ ] 我方單方面攻擊有完整進場、命中與回位。
- [ ] 敵方單方面攻擊有完整進場、命中與回位。
- [ ] 角色跳過後未消耗手牌。
- [ ] 已指派卡牌立即離開可選手牌。
- [ ] 回合結束保留未使用手牌。
- [ ] 下一回合只補牌至手牌上限5。
- [ ] HUD在世界鏡頭移動時保持固定。
- [ ] 1v1、1v4、2v4、3v3、4v1與4v4沒有角色或UI重疊。

## 證據要求

交鋒至少保留五個可辨識階段的截圖或短片：

1. 待機位置、敵方意圖與配對。
2. 雙方進場及技能揭示。
3. 技能／武器／FX實際對撞。
4. 敗方取消與勝方追擊。
5. 雙方回位且下一節拍繼續。

單張中央站位截圖不能證明完整交鋒。

## 測試事件記錄

測試模式應產生可核對的事件序列：

```text
CLASH_PAIR
MOVE_TO_CLASH
REVEAL_SKILL
CLASH_IMPACT
CLASH_WINNER
CANCEL_ACTION
FOLLOW_THROUGH
DAMAGE_OR_EFFECT
RETURN_STANDBY
NEXT_BEAT
```

事件記錄只能證明狀態機執行，不能取代畫面證據。

## 規則與演出分離驗收

規則測試負責交鋒配對、改線、勝負、取消範圍、節拍保留、牌庫與回合狀態。

演出驗收負責角色身份、進退場、技能卡、FX、停格、追擊、受擊、HUD固定及節拍銜接。

兩者都通過，才能使用第三級完成狀態。

