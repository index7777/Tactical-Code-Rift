# 現行戰鬥規格

STATUS = AUTHORITATIVE

《戰術編碼：裂痕》採原創混合制：保留集中戰鬥的技能目標、速度改線、交鋒勝負與單方面行動，並加入 DBG 共用手牌及卡牌時序。不是持續 CTB；每名角色每回合仍只有一個基礎行動。

## 不可移除核心

敵方先公開技能槽與目標；玩家依速度為每名角色選擇一張共用手牌或跳過；技能槽互相指向或較快角色改線時形成交鋒；雙方進入中央、揭示技能與威力、碰撞，敗方取消，勝方完成攻擊後返回固定待機位。

## 現行規則

- 每名存活角色每回合一個基礎行動；額外行動只能由明確效果產生。
- 敵我每回合重新擲速度。角色速度加上卡牌時序修正，形成本回合最終行動順位。
- 快卡較早、重卡較晚；時序只影響結算順位與能否改線，不直接增加交鋒威力。
- 正在被攻擊的原目標可正面迎擊；其他角色改線必須使最終時序高於敵方技能。
- 跳過不消耗卡牌，並給該角色下一回合一次性速度 +2；不可堆疊。
- 規劃尚未完成時按「下一回合」等同結束下令：保留已提交指令，所有尚未下令角色批次跳過並各自獲得下一回合一次性速度 +2，隨即開始本回合演出。
- 全隊共用牌庫；回合開始補至5張，未使用手牌保留。
- 規劃階段每輪可使用一次正式棄牌操作：明確棄掉一張尚未提交的手牌，本輪不立即補牌，下一回合再依手牌上限補牌。棄牌以失去該張牌及本輪一次棄牌機會為代價，不消耗角色行動；已提交卡、牌庫卡與演出階段均不可棄。
- 跳過不消耗卡牌。
- 速度與卡牌時序共同控制指令預覽、結算順序及能否攔截，不控制待機位置，也不產生持續 CTB 行動次數。
- 時間軸只顯示角色與當下最終時序值，不顯示已選卡牌名稱；牽制與卡片時序造成的提前／延後必須直接反映在位置和數字上。
- 一個敵方技能槽最多參與一次交鋒。
- 正在攻擊自己的敵方技能可正面迎擊；改線保護隊友時必須比敵方技能快。
- `堅守`只能指定出牌者自身：角色在自己的節拍原地立架並取得護盾，不生成刀路、不形成交鋒、不改寫殺生線，也不能保護其他角色。敵方仍沿原殺生線攻擊堅守者，傷害由當時已生效的護盾吸收。保護隊友必須使用`掩護`並通過截刀條件。
- 未配成交鋒的技能為單方面行動。
- 普通敵人使用有限且公開職能的意圖牌池：疾行妖偏高速 4–6、鎮岳鬼偏低速 5–7 與高架勢傷害、咒返妖偏中速 4–6 與干擾。混合敵群每輪最多一張威力 7，不允許依玩家出牌臨時生成反制牌。
- 三種普通敵人的規則差異必須可由出牌破解，不能只靠數值放大：
  - `疾行妖／殘影`：速度修正不大於 0 的攻擊，對未破綻、未崩勢的疾行妖交鋒威力 −2；單方面命中再減少 4 傷害。快牌可正常命中。
  - `鎮岳鬼／厚甲`：每輪第一次承受非破甲攻擊時減少 5 傷害且消耗厚甲；破甲牌不減傷並額外造成 2 架勢傷害。厚甲每輪重置一次。
  - `咒返妖／咒返`：威力 7 以上且不是破甲／牽制的攻擊，對未破綻、未崩勢的咒返妖交鋒威力 −2；單方面命中減少 4 傷害並令攻擊者損失 2 架勢。破甲、牽制或先製造破綻可避開反制。
- 怪物規則不得改寫既有殺生線、目標或行動順位；規則只在既定交鋒威力與命中交易中結算，並以`殘影／厚甲／咒返`短 FX 告知原因。
- 規則情報採情境式閱讀，不新增常駐教學框：玩家選中攻擊牌並指向敵人時，敵人身旁只顯示一個短標記。危險交互使用紅色，正確反制使用青綠色；移開目標即消失。
- `殘影`以多層輪廓側移、`厚甲`以甲片承擊碎散、`咒返`以逆轉菱印與反向衝擊表現。三者共用程式化 FX，不增加敵人方向圖或逐格動畫。
- 通用牌庫固定使用八種卡型：`快斬`、`重斬`、`破甲`、`堅守`、`掩護`、`接力`、`整備`、`牽制`。角色能力確定前不得加入角色專屬牌。
- `整備`只處理角色戰鬥狀態，不操作牌庫：消耗出牌者本輪行動，指定自身，恢復 3 點架勢並清除破綻。若出牌者已崩勢，仍依崩勢規則取消尚未執行的整備；整備不能恢復本輪已取消的行動。
- `上一步`不是常駐操作；規劃階段至少已提交一張卡後才顯示，回合開始演出後立即隱藏並停用。單純選牌、選棄牌或只有跳過不算已出牌。
- `牽制`是可交鋒的低威力干擾攻擊，使指定敵方技能的本輪最終時序 −2；不增加行動次數，也不改寫敵人原始攻擊目標。
- 同一敵人有其他可用意圖時，不得連續兩輪使用相同意圖；混合敵群仍維持單輪最多一張威力 7。
- 援攻是主要攻擊結束後的追加單方面攻擊，不重新使用已消耗的敵方技能交鋒。
- 不使用撲克花色、牌型、鬼牌、固定五槽、共享 AP 或回合末固定合體技。

## 演出

待機位置固定且與速度無關。HUD與世界鏡頭分離。交鋒必須同時呈現雙方進場、技能卡、最終威力、碰撞結果、敗方取消、勝方追擊與返回。多個實際相鄰的同目標行動才可銜接鏡頭，不得為演出重排時間線。繼刀屬於同一段演出交易：首擊後目標維持交鋒位置與後仰僵直，首位退場與繼刀者進場同時發生；最後一刀結束才判定目標倒地留在原地或返回待機位。

### 結果術語

- `破招`：單次交鋒落敗；敗方本次技能取消、後仰並產生破綻，勝方接續正式攻擊。只代表招式被破解，不代表架勢歸零或死亡。
- `崩勢`：架勢歸零；取消尚未執行的行動並進入易受終結狀態。
- `斷命`：HP 歸零；角色死亡、移除後續節拍與可選目標資格。

### 狀態與死亡生命週期

- `破綻`與`崩勢`都維持到本輪演出全部結束；建立下一輪、重新擲速度前清除。崩勢不跨輪延續，也不得在同輪中自行恢復行動。
- 斷命立即優先於已提交指令：死者尚未執行的攻擊、繼刀、掩護與支援全部取消，不產生效果；但玩家已完成提交的卡仍視為本輪消耗並在結算進入棄牌堆，不因角色死亡退回手牌。
- 已經開始的同一命中交易可以完成死亡落地，但死者不得再作為下一個接力者、掩護者、行動者或可選目標。
