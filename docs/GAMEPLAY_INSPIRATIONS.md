# 玩法參考與原創延伸

**狀態**：現行方向  
**確認日期**：2026-08-14

## 主要玩法參考

《戰術編碼：裂痕》的交鋒玩法主要延伸自：

- 《Limbus Company》
- 《Library of Ruina》

參考的是高層玩法語彙：多角色行動編排、攻防意圖、指定目標、行動交鋒、威力比較、格擋／破招，以及依序觀看行動結果。

這項定位取代「只有 FF6 ATB」的舊理解。FF6 仍是早期獨立計時、魔石式長期養成及飛空艇群像節奏的參考，但不是目前交鋒玩法的唯一或主要來源。

## 本作原創延伸

本作不直接複製上述作品的完整戰鬥流程，而是加入並整合：

1. **脈衝時序（Pulse Timeline）**：四名角色獨立充能，Ready 決定誰可以進入行動編排。
2. **共享 AP**：全隊共用連攜資源；不同角色首次行動與同角色追加行動具有不同成本。
3. **三槽連攜**：一次提交最多三個行動，支援多人接力或單人二連／三連。
4. **指定目標與攔截**：攻擊敵方攻擊者可形成正面交鋒或替隊友攔截。
5. **前排阻擋**：敵人攻擊後排時，同橫列前方角色可能改變實際受擊目標。
6. **陣型推進**：普通行動只作演出位移；連擊終結或特殊能力才永久推動陣型。
7. **雙層晶片構築**：永久晶片建立角色底盤，臨時晶片在單輪內改變交鋒與連攜規則。
8. **Zone 輪迴**：戰鬥編排與肉鴿路線、事件、商店、返航保留／清空共同構成完整循環。

## 目前程式對應

| 程式模組 | 對應玩法 |
|---|---|
| `AtbBattle.ts` | 脈衝時序、Ready、Active／Wait |
| `ActionPoints.ts` | 共享 AP、同角色追加成本 |
| `RelayClash.ts` | ATK／DEF／ULT、威力比較、破招、格擋與交鋒結果 |
| `TargetClash.ts` | 指定目標、互相交鋒、攔截、前排阻擋及同目標序列 |
| `BootScene.ts` | 三槽連攜、二連／三連終結、陣型位移與戰鬥演出 |
| `RouteGenerator.ts` | Zone 節點基礎生成 |

## 參考邊界

可以參考：

- 戰術決策的資訊結構
- 行動意圖與交鋒的可讀性
- 多角色編排造成的取捨
- 攻擊、防禦與高階行動之間的反制關係
- 行動結果依序演出的節奏

不得直接複製：

- 遊戲名稱、世界觀、角色、組織、劇情或專有名詞
- 原作 UI 排版、圖標、卡面、色彩組合或動畫構圖
- 原作技能名稱、數值表、公式、角色能力或關卡內容
- 原作圖片、音效、字型、程式碼或其他受保護素材
- 足以讓玩家誤認為同系列作品的整體視覺與宣傳表述

## 對外描述原則

對外不使用「複製」「復刻」或「某作品換皮」。建議描述為：

> 四人脈衝時序與三槽連攜結合的目標交鋒 RPG。玩家根據敵方意圖，以共享 AP 編排行動，觸發交鋒、攔截、格擋、追擊與陣型推進。

遊戲參考來源可在開發紀錄或訪談中誠實說明，但商店頁面應優先描述本作實際機制與差異。
