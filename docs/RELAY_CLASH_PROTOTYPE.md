# 接力交鋒試玩原型

- 模式：1V1、2V1、3V1。
- 每名我方角色對應一個序列槽與一次進場攻擊；敵方目前由同一目標連續應對。
- 點擊我方卡片可輪替 `ATK → DEF → ULT`；ULT 固定高優先並胜过所有普通卡。
- 执行时双方沿横轴进入交锋点，依结算产生抵消、破招、格挡或必杀，再归位并由下一角色补位。
- 第一版敌方序列固定为 `ATK 3 / ATK 2 / DEF 4`，用于验证用户提出的案例。
- 当前伤害采用点数差；本原型优先验证规则可读性、换位节奏与动画爽感，不代表正式数值。
- 战线为持久状态：胜方推进、败方击退、抵消后双方停在新的交锋位置，不在每槽结束时返回初始站位。
- 下一角色在上一角色退至后排时补位；战场容器追踪当前交锋点，碰撞时加入镜头推进、缩放与震动。
- 基础交锋严格共用同一水平轴：敌方永远在左、我方永远在右，并保持最小安全距离；不得穿身、绕背或交换阵营侧。只有未来明确带有 `FLANK／TELEPORT／PIERCE_THROUGH` 标签的技能可以覆盖这条规则。

## 玩法來源定位

本原型的多角色行動編排、攻防卡交鋒與依序結算，主要延伸《Limbus Company》及《Library of Ruina》的高層玩法語彙；本作再加入脈衝時序、共享 AP、三槽連攜與陣型推進。完整邊界見 `GAMEPLAY_INSPIRATIONS.md`。
