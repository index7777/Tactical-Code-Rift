# 核心玩法決定與衝突紀錄

## 已採用方向

| 項目 | 本版決定 | 取代的舊方向 |
|---|---|---|
| 回合骨架 | 固定五槽位、依序翻牌交鋒 | 三槽 AP 連攜 |
| 人數 | 敵我各自可設 1–5 人，五槽按人數分配 | 固定三人展示／四人 ATB |
| 時序 | 槽位 1–5 即時間軸 | ATB、Pulse、速度條 |
| 資源 | 核心試玩不使用 AP | 共享 AP 與追加成本 |
| 勝負 | 同槽比較牌面點數 | ATK/DEF/ULT power 比較 |
| 牌型 | 提供終結技資格與等級 | 無標準五張牌型 |
| 花色 | 只判定同花系牌型 | 花色附帶戰鬥能力 |
| 美術 | 原創冷色裂痕 HUD＋實體牌面 | FF6 風格選單 |

## 仍需和製作人確認

1. **手牌選擇量**：目前採「抽 7 選 5」，讓玩家有真正決策；若改成只抽 5 張，流程更快但接近純運氣。
2. **鬼牌控制權**：目前自動最佳化；可改為玩家在鎖定前手動指定牌與花色，策略更深但操作成本更高。
3. **鬼牌槽位點數**：目前使用其最佳牌型代用點數；可改為固定 15、固定 0，或只完成牌型而不參加槽位比點。
4. **終結條件**：目前「至少 3 槽勝＋一對以上」。要決定是否讓順子以上即使只贏 2 槽也能啟動，或以贏槽數加成傷害。
5. **護盾數值**：目前每名角色回合開始 20、單槽傷害 18；這只是視覺測試值，尚未完成平衡。
6. **目標與攔截**：本版同槽角色直接交鋒，尚未加入玩家手動指定目標、單方面攻擊與攔截改線；這是下一層系統，不宜在核心牌局未確認前增加。
7. **角色技能差異**：目前角色只有槽位歸屬與色彩辨識；要決定角色技能是改牌、換槽、護盾，或只改行動結果，避免重新引入難懂的第二套算式。
8. **牌型比較用途**：目前敵我牌型不互相比大小，只各自檢查終結資格；若改成互比，可能讓已贏三槽的一方仍被整手牌型推翻。
9. **倒地與勝敗**：目前 HP/護盾可受傷但沒有完整戰鬥結束、補牌與多回合敵方 AI，待核心交鋒確認後補上。
10. **同角多槽演出**：1 人持有 5 槽時目前連續出擊；要決定是否加入疲勞、連段升級或鏡頭演出變化，但不建議先加數值懲罰。

## 明確衝突

- 若重新加入速度／ATB，會和「五槽就是可預讀時間軸」重複，玩家同時要理解兩種出手順序。
- 若 AP 同時限制出牌張數，會破壞每回合必須形成標準五張牌型；若未來保留 AP，建議只限制額外改牌或技能，不限制五張基本出牌。
- 若牌型直接決定整回合勝負，會讓逐槽交鋒演出失去意義；建議維持「槽位決定行動，牌型決定終結」。
- 若每種花色再綁攻防屬性，玩家會同時算點數、牌型、花色技能、角色技能與目標，超出第一版易讀範圍。

## 已解決：時間線與出牌槽

先前把五個出牌槽直接當成時間線，已確認會限制速度、目標與單方面行動。新版決定如下：

- 速度只負責在進入戰鬥時建立角色時間線與 HUD 預讀順序。
- 五個出牌槽只負責把牌與攻擊／支援意圖裝入接下來五個我方行動節點。
- 時間線決定何時行動；拖牌目標決定對誰做什麼；單張牌決定交鋒數值；五張牌型決定終結資格。
