# 目標交鋒規則

- 戰鬥以固定槽位依序結算：槽 1 完整結束後才進槽 2，再進槽 3。
- 每個槽只讀取該槽的我方行動與敵方行動，不跨槽搶先攔截或配對。
- 每張 ATK 卡必須指定敵方目標；不同目標的交鋒可以平行演出。
- 同一目標的多名攻擊者依序進場；前一名完成交鋒後，下一名才補位，不共用同一座標。
- 敵 A 攻我方 A，而我方 B 的 ATK 指定敵 A 時，B 會到 A 前方攔截並進行 ATK 判定。
- DEF 只保護自己並停在原地，不會主動移動去保護隊友；未來只有 COVER 類技能可例外。
- 前排阻擋：若指定目標前方已有另一名我方角色，敵方攻擊會改打最先碰到的角色。
- 同隊角色不會互相阻擋；1 對 3 時三名敵人仍可依序攻擊唯一目標。
- 集中攻擊同一目標時，每次命中都將目標往後擊退；下一槽攻擊者追上目標的新位置補位，不擠開己方角色。
- 角色的陣型座標與交鋒演出座標分離；Clash、追擊、攔截完成後雙方回槽。
- 單次行動不永久擊退；只有同一角色以 AP 形成二連或三連時，最後一擊才改變受擊方陣型座標，三連末擊的擊退更強。
- 普通攻擊不得穿人、繞背或跨過前排；只有明確標示的特殊技能能例外。
- 角色只沿橫向接敵，不提供八方向移動。

## 玩法來源定位

指定目標、互相交鋒、攔截與攻防意圖的設計，主要延伸《Limbus Company》及《Library of Ruina》的戰術交鋒方向；前排阻擋、同目標分組與 Pulse／AP 整合屬本作延伸。完整邊界見 `GAMEPLAY_INSPIRATIONS.md`。
