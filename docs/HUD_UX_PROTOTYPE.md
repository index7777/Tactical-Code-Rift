# HUD／UI／UX 試玩版規格

## 體驗目標

玩家在三秒內理解「四人各自充能、只有 Ready 角色能下指令」，並能以滑鼠、觸控或手把完成：選 Ready 角色 → 選技能 → 點敵人 → 觀看執行 → 回到待機。

## 五個介面狀態

1. `IDLE`：戰場優先；底部四張晶片角色卡常駐，顯示 HP 與 Pulse。
2. `READY`：滿值卡片以青色线路高亮；第一名 Ready 自动成为目前输入角色。
3. `COMMAND`：左下展开原创切角指令盘；其他角色卡仍显示计时。
4. `TARGET`：指令盘收起，敌人显示目标游标，可直接点击或确认。
5. `EXECUTE`：攻击者前进、命中、目标受击、双方归位；之后恢复前一输入状态或待机。

## 输入

- 鼠标／触控：点 Ready 角色卡、点指令、点目标。
- 键盘：上下选择、Enter 确认、Esc 返回、Tab 切换 Ready、M 切换模式。
- 手把：十字键选择、A 确认、B 返回、RB 切换 Ready、Y 切换模式。
- 未 Ready 的角色卡可查看但不可取得指令权，点击必须提供明确提示。

## 原创视觉

- 深墨黑 HUD、冷青 Ready、珊瑚指令边线、琥珀充能。
- 角色卡使用单边色轨与晶片线路，不使用皇家蓝、白色双框或 FF6 选单比例。
- 玩家可见名称使用 `PULSE／脉冲`，不显示 ATB。

## 横向与安全区

- 逻辑画布 1280×720；底部 HUD 高 160（22.2%）。
- 互动目标最小约 44 CSS px；等比缩放到手机横向后仍需实机验证。
- 左右各预留 18px 逻辑安全边界，平台封装时再加入实际 safe-area inset。
